   3.2 REQUIREMENT GAPS

   GAP-01 | API Design Formalization
   Source: /project-docs/08_api_planning/00_api_endpoint_registry.txt is a
   planning document. Formal OpenAPI YAML spec does not yet exist.
   Action: Generate from Spring Boot @Operation annotations once backend
   scaffolding is set up.

   GAP-02 | PDF Report Layout Specification
   Source: /project-docs/07_dashboards_and_reports/00_dc_dashboard.txt
   The PDF export format for official DC reports is not specified.
   Action: Get sign-off from HR&CE department on PDF template layout
   (cover page, field order, official header).

   GAP-03 | Seed Data Specification
   Source: /project-docs/04_schema_design/01_geo_hierarchy_schema.txt
   The complete Karnataka geo hierarchy (district/taluk/hobli) seed data
   is not in the repository.
   Action: Obtain official Karnataka government administrative boundary data
   (available from data.gov.in or Karnataka Census data) and create a
   Flyway seed migration.

   GAP-04 | Notification Template Content
   Source: /project-docs/04_schema_design/09_notification_schema.txt
   Email and SMS notification content (subject lines, body templates)
   are not defined.
   Action: Write 13 email templates and 8 SMS templates (shorter versions)
   signed off by HR&CE communications team.

   GAP-05 | Performance Benchmarks
   Source: /project-docs/00_context/02_go_live_blockers.txt (F-02)
   No formal performance benchmark figures exist beyond "3 seconds for
   district-wide search."
   Action: Define complete performance SLAs for all high-traffic endpoints
   before load testing begins.

   GAP-06 | Disaster Recovery Plan
   Source: /project-docs/10_delivery_and_ops/01_scheduled_jobs_ops.txt
   RDS backup and RTO/RPO targets are mentioned but no formal DR runbook exists.
   Action: Write DR runbook with step-by-step recovery instructions.
