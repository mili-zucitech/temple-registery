## SECTION 6 — UI ANIMATION INSTRUCTIONS

### Core UI Treatment
Every product screenshot must be treated as follows:

1. **Depth layering:** Apply CSS-like depth to the UI — front elements closer, background elements receded. Creates natural 3D parallax.
2. **Glassmorphism overlay:** Semi-transparent frosted glass panel beneath the UI. `background: rgba(255,255,255,0.07); backdrop-filter: blur(12px); border: 1px solid rgba(230, 148, 25, 0.3);`
3. **Ambient glow:** Soft amber halo behind each UI panel. `box-shadow: 0 0 80px rgba(230, 148, 25, 0.15);`
4. **Entry animation:** Each UI panel slides in from bottom with fade. Duration: 0.8s ease-out.
5. **Idle animation:** Subtle "breathing" scale oscillation `1.000 → 1.005 → 1.000` over 4 seconds. Almost invisible but alive.

### Specific Interactions

**Stat Tiles (Admin Dashboard):**
- Numbers count up from 0 to actual value over 1.2 seconds
- On hover/tap: tile lifts 4px, amber glow intensifies, number briefly scales 1.1x

**Charts (Bar/Pie):**
- Bar charts animate from bottom to top: stagger each bar by 0.1s
- Pie chart: spins clockwise 1 full rotation → locks to final position
- Grade colors match the product's actual color scheme

**Workflow Arrows:**
- Light particles travel along the arrow paths
- Direction: left → right for approval flow
- Speed: faster near APPROVED end (momentum metaphor)
- Particle color: amber for active path, grey for inactive

**Notification Badges:**
- Pulse animation: scale 1.0 → 1.3 → 1.0, 2-second loop
- Color: #E69419 background, white number
- Sound: paired with 320Hz clean sine tone

**Approval Seal Animation:**
- Starts as a circle of light
- Rotates once
- Locks with a satisfying "stamp" motion
- Final state: official circle with checkmark in center, amber + gold coloring
